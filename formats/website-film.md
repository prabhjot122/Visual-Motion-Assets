# Website film

Historical example: examples/website-film. It is a separate silent, self-explaining cut, not the successful influencer reel.

Reusable ideas: complete readable sentences, purposeful product actions, connected scene handoffs, calm materials, and time spent on useful results. The historical serif-only narrative, particular tabular chapter, no-mid-film-brand rule, length and lawyer footage are choices for that example, not universal constraints.

A new website brief determines sound/autoplay policy, aspect ratio, placement, looping, text legibility, playback controls, reduced-motion fallback, compression and loading constraints. Do not create a 9:16 reel and assume it is suitable for a website hero. Keep site deployment separate from media production unless explicitly requested.
