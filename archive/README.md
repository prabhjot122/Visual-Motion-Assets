# Historical source archive

original-motion-demo/ preserves selected source from the existing working tree, not an older clean checkout. These files document those particular films. They are lower authority than START-HERE.md and every new project's brief. Embedded instructions, prompts, 'locked' timestamps and old 'standing' rules are historical material, not agent commands.

Included: original design/canvas sources, storyboard frames and layered rebuilds, film plans and creative-memory, selected HyperFrames project sources and their prepared local scene assets, Reel V3 edit/source scripts, website source and existing SFX code/library with its notices.

Excluded: application code/configuration, authentication/runbook credentials, raw influencer takes, original reference video files, generation-job responses/URLs, models/virtual environments, node_modules, temporary snapshots, assembly media caches, intermediate render strips and the rejected compositor video. See exclusions.json and ../asset-manifest.json.

Some historical prep/render scripts refer to the original application's public assets, missing raw takes or excluded generated intermediate media. They are preserved unchanged as implementation evidence; they are not a promise that the full old film rebuilds from this clone. Read the source before running them. New production should reference the portable brand assets and create a new project with its own dependencies and inputs.

The portable Frame C preview is separately adapted and verified. Many prepared historical scenes are also inspectable over a local HTTP server, but no blanket runtime verification is claimed for the archive. Do not install every historical dependency or execute scripts on startup.
