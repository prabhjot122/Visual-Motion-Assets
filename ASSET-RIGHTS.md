asset-manifest.json records source-relative paths, destination paths, byte counts, SHA256 and status for every imported asset. Unchanged copies and the single adapted active Frame C preview are distinguished. Source hashes come from the existing working tree, not an older clean Git revision.

media-index.json measures included representative exports. The original high-quality V3 and website masters remain in the source workspace; this package uses existing share/preview files to avoid unnecessary large duplicates. New production must render from suitable inputs rather than enlarge these previews.

archive/exclusions.json lists omitted material. A fresh clone can read the guidance, inspect examples and serve the portable Frame C offline. It cannot reproduce the full old V3 without the excluded raw takes, voice/music assets, strips and original environment. Preparation scripts in the archive can refer outside this clone; read them as historical source, not guaranteed startup commands.

Public-package checks exclude credentials/account instructions, raw influencer takes, machine job responses, model/dependency folders and render caches. The source application working tree remains unchanged. User selection of V3 and rejection of the earlier export are recorded from the 31 October 2026 handoff conversation; no external assistant memory files were modified.
