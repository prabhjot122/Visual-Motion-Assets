## The connecting idea (unchanged in principle)

One continuous camera over one paper desk, led by one **clay thread**, with **pencil corner marks** that travel between focal elements and **stone only where it means something**:

- the A/B columns at a true 2 : 1 ratio;
- slab wipes for context changes: clay = Arora, char = Arif Jafar scan, sand = Vikram.

New in this revision: the thread's origin and end are **the LawVriksh mark itself**. The mark's clay circuit nodes and root ground line are the thread, so the brand moment is where the thread is born (B1) and where it returns (C4).

The problem sequence (0–24.78 s) has **no app screens**. It builds a chain where each idea is literally made from the previous one's material:

**sheet → stack → page volume → handwriting → ticks → one thread → point → tree → case seed → opened file → three real documents → two colliding figures → provisions pinned to documents → dates peeled off documents → knotted timeline → straightened line → edge of the first product window.**

Rhythm deliberately contrasts. **Slow, plodding** manual hops (O4) meet **one fast continuous sweep** (O5). A **still, spacious** brand moment (B1) meets an **explosive** opening of the case (P2). A **collision** (P4) meets a **readable hold** on the knot (P6).
