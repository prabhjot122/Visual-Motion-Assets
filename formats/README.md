# Choose the relevant format

- [Voiceover reel](voiceover-reel.md): script and narration, no influencer by default.
- [Static post / carousel](static-and-carousel.md): the same identity with its own information hierarchy.
- [Website film](website-film.md): visual-only explanation and reading rhythm.

Output dimensions, duration, safe areas, caption policy, audio and delivery codec belong to each project. 9:16 / 1080x1920 is a useful Instagram-reel starting specification, not a rule for every channel or asset. The old 1440x1000 graphics canvas was a source composition, not a universal final canvas.
