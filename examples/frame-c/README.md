# Frame C — approved appearance

Open [frame-c.html](frame-c.html) through the root HTTP preview command. This is a portable copy of the approved standalone frame, with remote font styles replaced by bundled local fonts and texture/logo paths redirected to brand/. Layout and content are preserved.

The original frame and Claude Design canvas source are retained under ../../archive/original-motion-demo/design/. The approved frame is a look reference, not a universal arrangement of case-map nodes.

Use the storyboard style frames in style-frames/ to see this language across multiple features. One frame does not require every new reel to centre on Case Map.

The historical Claude Design motion study was rejected. Its choreography, camera and timing are not approved by Frame C's appearance approval. The old design README's 'awaiting review' label is historical and superseded by that rejection.
