# Delivery review

- Brief coverage: each promised idea has understandable treatment; no named feature is an accidental flash.
- Brand: type, palette, material scale, light and mark match current shared guidance.
- Continuity: a reason for each transition; varied rhythm; no unrelated animations merely chained together.
- Legibility: review at final phone/site size; reading time begins when content is complete; safe areas/caption overlaps checked.
- Evidence: source claims correct; demo/source contexts distinct; no illustrative process presented as a fresh live run.
- Visual integrity: inspect beginning/end, section seams, motion interiors, crops, text wrapping, highlights, empty borders and accidental freezes.
- Audio for video: supplied words preserved within authorized edits; sync checked; chosen loudness/peaks measured; music/SFX rights and levels documented.
- Technical for video: probe actual dimensions, duration, frame rate, codec and audio; decode whole output for errors; check representative transitions.
- Static/carousel: each export inspected at intended size, slide order and complete copy checked, editable source and agreed alt text delivered.
- Provenance: final filenames, sources, asset permissions, commands, dependencies and unresolved limits recorded.
- Review honesty: state which perceptual listening/playback checks actually happened. A technical pass is not user approval.
- Feedback saved to the project; shared learning promotion is explicit.
